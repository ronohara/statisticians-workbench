# Statisticians Workbench — Python backend runtime dependencies
#
# This is the RUNTIME subset: the distributions imported by main.py and the
# modules it reaches. It is deliberately shorter than the development
# requirements, which also pin the test and tooling stack (scipy, statsmodels,
# scikit-learn, tokenizers, tiktoken, huggingface_hub, ...). None of those are
# imported by the running backend: the statistics under
# src/routers/recipes/stats/ is dependency-free by design and is verified
# against scipy golden values in the test suite, not at runtime.
#
# Every version below is the one the development environment runs, so a working
# development install and this list agree.
#
# Two entries are here because a package's own rules do not cover them:
#
#   watchfiles     uvicorn ships it only in its "standard" extra, but main.py
#                  starts uvicorn with reload=True, which needs it. Without it
#                  the backend fails at startup, not at first use.
#   PyMySQL        imported directly by src/routers/dbdesign/schema.py.
#                  aiomysql would install it anyway, but a direct import must
#                  not depend on another package's transitive requirement.
#   python-multipart
#                  required by FastAPI for UploadFile/File/Form, which
#                  src/routers/notebooks/router.py uses.
#
# Install with:  python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
